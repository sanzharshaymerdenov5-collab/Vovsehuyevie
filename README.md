# Официальная Вики сериала «Во Все Хуёвые»

Интерактивная база знаний и энциклопедия пародийного сериала **«Во Все Хуёвые»** (пародия на Breaking Bad). Сайт выполнен в стиле классических вики-проектов (Fandom / MediaWiki) с подробными инфобоксами персонажей, сводками криминальных группировок Подзалупинска, каталогом серий, хронологией событий и интерактивным графом связей.

---

## 🚀 Как открыть и собрать сайт

1. **Онлайн (GitHub Pages)**: [https://sanzharshaymerdenov5-collab.github.io/Vovsehuyevie/](https://sanzharshaymerdenov5-collab.github.io/Vovsehuyevie/)
2. **Локально без сервера**: просто откройте **`index.html`** двойным кликом в любом современном браузере.
3. **Локальный HTTP-сервер** (для проверки чистых URL и Service Worker):
   ```bash
   python3 -m http.server 8765
   ```
4. **Пересборка статических страниц и `sitemap.xml`**:
   ```bash
   node scripts/build-pages.js
   ```
   Скрипт генерирует индексируемые `#`-free HTML-страницы для каждого маршрута (`/characters/`, `/factions/`, `/episodes/`, `/timeline/`, `/graph/`, `/character/<id>/`, `/faction/<id>/`, `/episode/<id>/`, `404.html`) и обновляет `sitemap.xml`.

## 💎 Главные возможности

- **Чистые индексируемые URL без `#` (History API + статический пре-рендер)**:
  - Все разделы и статьи доступны по чистым адресам без хеш-фрагментов, снабжены `<link rel="canonical">`, Open Graph, Twitter Cards, Schema.org JSON-LD и полным `sitemap.xml`.
  - Старые закладки с `#...` автоматически переводятся на чистые URL без потери маршрута.
- **Персонажи и детальные инфобоксы (7 каноничных героев)**:
  - **Валентин Белинский (Хуйзенберг)** — с фотографией и WebP-миниатюрами (`assets/valentin.jpg`, `valentin.webp`)
  - **Джесси Розовый** — напарник по варке и главный герой фильма
  - **Стояк Белинский** — специальный агент ОБН Подзалупинска
  - **Скулер Белинская** — жена Валентина
  - **Сосик Гудман** — криминальный адвокат (отбывает срок)
  - **Гей Химбиович** — с фотографией (`assets/gey-himbiovech.jpg`, `gey-himbiovech.webp`)
  - **Гусев Ферангий (Гусь)** — с фотографией (`assets/gusev.jpg`, `gusev.webp`)
  - Упомянутые, но ещё не добавленные герои отображаются аккуратными красными ссылками MediaWiki (`mw-redlink`, статус «в разработке»).
- **Группировки и организации Подзалупинска**:
  - **Наркоимперия Хуйзенберга**
  - **Наркоимперия Гусева Ферангия** (под прикрытием кафе «Голубой шампур»)
  - **ОБН Подзалупинска (ГНК)**
- **Рабочий раздел «Серии» + страницы-заглушки**:
  - Полный список из 8 каноничных выпусков: 7 серий («Пилот Мефедрона» … «Хуелина») и полнометражный фильм «Путь розового?».
  - Отдельная страница каждого выпуска открывается в формате чистой заглушки («Страница в разработке») с навигацией к соседним выпускам.
- **Интерактивный граф связей (`/graph/`)**:
  - Интерактивная SVG-схема персонажей, фильтрация по группировкам, выбор узла мышью или с клавиатуры и панель подробных связей.
- **Мгновенный поиск (`/` или `Ctrl+K`), «Случайная статья» (`🎲`) и копирование ссылок**:
  - Поиск по биографиям, псевдонимам, характеру, фактам, категориям, группировкам и сериям с подсветкой совпадений `<mark>` и полной навигацией с клавиатуры (`↑`, `↓`, `Enter`, `ESC`).
  - Кнопки копирования ссылки на статью или конкретный раздел, кнопка «Наверх» и кнопка случайной статьи.
- **Доступность (WCAG 2.1 AA) и PWA-офлайн**:
  - Светлая и тёмная темы с контрастом `>= 4.5:1` для статусов, штампов и кнопок, фокус-трап в модалках, ARIA-роли и `manifest.webmanifest` + `sw.js`.

## 🧪 Тестирование

```bash
node scripts/build-pages.js --check
node tests/e2e_runner.js
```

Автоматизированный прогон входит в CI (`.github/workflows/test.yml`).
